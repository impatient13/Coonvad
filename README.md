# Overview

This project provides a custom interface and visual style based on the Mullvad VPN client architecture.

## Features

* Custom UI/UX theme and visual overhaul based on Mullvad VPN
* Secure network routing and privacy preservation
* Lightweight and clean structure

## Project Structure

* `coonvad.py`: Core application script and backend logic.
* `coonvad_logo.jpg`: Project brand asset.

## Getting Started

1. Ensure Python 3.x is installed on your system.
2. Run the main application script:
   ```bash
   python Coonvad\ VPN/coonvad.py
   ```
3. Make sur to have Mullvad VPN installed
   https://mullvad.net/fr/account/create
